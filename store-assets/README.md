# LCS Tracker by AQAS — Google Play Store Assets

This folder is for store-listing assets only. It does not change the app code or release branches.

## App icon
- Source artwork: `app-icon.svg`
- Google Play listing icon must be exported as a **512 × 512 PNG or JPEG**, up to 1 MB.
- The SVG is an editable source; upload a PNG/JPEG export in Play Console, not the SVG.

## Phone screenshots
Place genuine screenshots captured from the current LCS Tracker app in `screenshots/`.
Recommended set:
1. Dashboard / order summary
2. Order list with shipment statuses
3. Order details
4. Receipt upload / scan flow
5. Search and status filters
6. Sync All progress (only if shown in the current build)

Do not use fabricated UI or screenshots from Play Console. Make sure customer names, phone numbers, addresses, consignment numbers, and other private data are hidden or replaced with test data before publishing.

Suggested filenames: `01-dashboard.png`, `02-orders.png`, `03-order-details.png`, `04-receipt-upload.png`, `05-search-filters.png`, `06-sync-progress.png`.

Check current Play Console requirements for accepted screenshot dimensions and count before upload.
